Bubble series: proportional symbols

The right mark for absolute magnitudes. Area is proportional to value (square-root radius scaling), largest painted first so small circles stay clickable, and the legend nests three reference circles so areas can actually be decoded. Zoom in: the circles hold their size, because a radius that grew with the camera would no longer encode the value. Hover near a small bubble rather than on it: the nearest mark within 20px catches the pointer, so a 3px circle never demands a 3px hit (interaction.nearest to tune or disable).

Why square root is the default

With linear, radius grows with the value, so a city twice the size draws four times the ink. Switch the select and watch Tokyo swallow Japan: the ranking survives but every comparison is overstated. The option exists because some publications standardise on it, and it warns in dev mode. 

{
  type: 'bubble',
  name: 'Metro population',
  data: [{ name: 'Tokyo', lon: 139.69, lat: 35.69, value: 37400068 }],
  size: { scale: 'sqrt', range: [3, 30] },
  colorScale: { palette: 'reds' },   // optional second variable
  colorField: 'growth',
}
