Ignite UI theming

One line, import 'apexmaps/ignite-ui' (or the apexmaps.ignite-ui.min.js script tag here), and the map follows the Ignite UI theme on the page: series colours from the theme's seeds, text, borders, the focus ring, the tooltip, the font, the basemap and no-data greys, and light or dark. The map itself sets no theme option. Without the add-on an Ignite UI sheet changes nothing. Anything you set (options, --apexmaps-*, --apx-*, a palette) still wins, and the choropleth ramp stays sequential.
