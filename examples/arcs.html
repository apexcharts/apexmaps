Arc series: great-circle routes

Singapore's long-haul network, drawn as great circles. The routes to Los Angeles and Vancouver cross the Pacific, so they are cut at the antimeridian and re-enter on the left edge instead of streaking back across the map. The São Paulo route sweeps south past the Cape, which is genuinely the shortest path. Thin arcs carry an invisible wider hit path so they stay hoverable: a 1px flight line is otherwise unpointable, and widening the visible stroke would misrepresent the value it encodes.

Geodesic, or decorative

geodesic: true (the default) follows the real great circle, resampled densely enough to stay smooth at any zoom and split where it crosses the antimeridian. Turning it off draws the straight line between the two points, which in Mercator is not the route a plane flies. curvature bulges the arc perpendicular to its chord: decorative, so it is off by default and mutually exclusive with geodesic accuracy. 

{
  type: 'arc',
  name: 'Weekly flights',
  data: [{ from: [103.99, 1.36], to: [-0.45, 51.47], value: 900 }],
  geodesic: true,
  width: { range: [0.6, 4] },
  endpoints: { show: true, radius: 2.5 },
}
