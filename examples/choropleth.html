Choropleth, default configuration

No styling passed: Equal Earth projection, quantile classification, an OkLab-sampled ramp, computed class breaks in the legend, and a no-data swatch. Click a legend class to mute it. Hover, scroll to zoom, drag to pan, double-click to zoom in, shift-drag to select.

The whole configuration

Two keys. Everything the map decides beyond this, it decides because the default is meant to be publishable rather than neutral. 

new ApexMaps(element, {
  geo: { map: 'world/countries@110m' },
  series: [{ name: 'Index score', joinBy: 'name', data }],
